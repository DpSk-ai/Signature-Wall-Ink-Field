# 字体资源与授权

交付 24 个字体家族、2,771 个本地 WOFF2 文件，共 99.7 MiB。按字体家族和 Unicode 分片请求，24 个 CSS 家族均由实际字体文件支撑。

22 个家族随附 SIL Open Font License 1.1，俐方体与精品点阵保留各自的字型内附许可及其 M+ 等上游声明。每个家族的独立许可位于对应目录的 LICENSE.txt；分发器的 MIT 许可单独保存。授权依据、版本和字形覆盖以此包实际文件为准。

基本汉字数为本包真实 cmap 中 U+4E00–U+9FFF 区间的去重数量。coverage.json 还记录各家族其他 Unicode 覆盖。样本“山川”的 24 张字形位图散列互不相同，所有字样均通过 Chromium 实际渲染字体查询。

辰宇落雁、清松手写取自作者发布的 TTF，按字符分片并另取内部名称 Ink Field Study CY / JS，保留字形、作者声明、原始文件 SHA-256 与 OFL。其他家族采用固定发布包中的 Web 字体，保留其二进制；font.css 仅引用本地文件。部分繁体字库的简体覆盖较少，选择时会显示补字提示。
