# 墨场 Ink Field · 视觉与交互规范

## 作品构想

每个参与者在一张共同的墨场里留下自己的字形。远看是一件有体积的折叠线束雕塑，近看是各自独立的署名。墨线折返的方向、纸张与展场的明暗、相同的投影坐标贯穿手机、大屏和纪念图。赛事文字取自提供的海报。英文作品名、墨场二字和线束符号属于互动作品自身的视觉语言。

## 三案比较

| 设计维度 | A · 光谱切片 | B · 活字排演 | C · 墨场 |
|---|---|---|---|
| 概念 | 一人点亮一块透光切片，众人形成展柜里的光谱 | 姓名是独立活字，集体写成一张未完成的校样 | 每次落款改变折叠墨带的截面，署名构成共同作品 |
| 色彩 | 深海蓝、冷白、琥珀黄 | 暖纸白、墨黑、朱红 | 深靛墨、淡紫、珊瑚橙与暖纸白 |
| 排版 | 细长无衬线展签、纵向刻度 | 大字号字样、基线与不对称字幅 | 罗马衬线配斜体作品名，现代无衬线赛事层，等宽坐标 |
| 图形 | 折射平面和截面序列 | 铅字框、校样线、定位十字 | 参数化扭带、细墨线、稀疏网点和定位线 |
| 大屏 | 信息在侧，姓名围绕切片 | 大标题与自由字幅交错，增员后压缩标题区 | 左上展名与主题，右上计数，跨幅署名场，右下扫码 |
| 手机 | 选择切片、署名、领取透光入场券 | 像排字台一样切换字样并确认校样 | 在暖纸工作台选字体，深色画布落笔，领取带坐标的回执 |
| 动画 | 局部切面点亮，姓名原位显现 | 每字顺序落墨，排版骨架固定 | 中线引导逐字显墨，人数驱动墨带形态与退让 |
| 成本 | 静态切面较轻，透明叠加增加填充成本 | 最低，主要绘制文字 | 中等，投影与深度排序按事件计算，动画只更新活动字幅 |

采用 C 的空间构图与 B 的字体标本系统。空场时墨带可以独立成画；百人时姓名需要最大的对比度与可读面积，降低墨带浓度即可让出前景。手机端以同一个“山川”字样做横向比较，选择后立即查看自己的姓名。A 的多个透光片在满墙时容易形成额外的文字边界，B 的大字排演则会和参加者的名字争夺尺度。

## 色彩与层级

| 用途 | 色值 | 用法 |
|---|---|---|
| 展场墨底 | #171521 | 大屏及手机作品区，点阵与分隔线低对比 |
| 暖纸 | #F5F1EB | 输入、控制台、签到回执 |
| 淡紫 | #D3BCF3 | 作品名斜体、选中标本、前景笔迹 |
| 珊瑚 | #FFA47F | 活动状态、线束受光面、提交动作 |
| 标本画布 | #282235 | 双轴刻线之上的姓名预览 |

英文展名使用系统罗马衬线，Field 以斜体保持两个词的张力。大屏明确保留 AI Coding Hackathon 与 TRAE on Campus @四川大学。署名使用 24 个本地字体家族，界面文字使用平台无衬线。辅助标记用等宽字。展项图形不代表赛事官方标识。

## 空间与密度

逻辑画面为 1920 × 1080。所有坐标、笔迹与导出共用这套坐标系。窗口改变比例时整幅画面等比居中。双方栏线固定，二维码有四个模块的留白。第一批姓名优先占用三个跨列空间，其余位置在错位的 12 列分区内分散取样。每个名字只在创建时取得位置；已隐藏的姓名仍占用自己的区域，恢复时回到原处。长中文名可分两行，大屏与导出采用同一断行点。

0 人展出完整雕塑与候场提示。1–5 人优先使用较大的签名字幅。10 人起，线束随人数逐渐降对比。50–120 人时仅保留较淡的表面纹理与稀疏网点。旧坐标落在新标题区域时，展签采用紧凑版本。

## 材质与运动

墨带通过二维参数取样成 128 段、48 道细线。扭转、投影、表面明暗与深度排序产生前后遮挡。人数决定扭转相位，同时按指数曲线降低底层墨色。空闲墙没有常驻背景动画循环。

字形轮廓来自选择的字体。已有笔顺数据的汉字根据 9,574 个字符数据条目中的中线施加画笔遮罩；中线和所选字体的笔锋可能不同，末段补齐选定字形。缺少笔顺数据的字符采用局部显墨。每个字在同一个持久坐标内完成。暂停会冻结当前笔迹；开启减少动态效果时显示完整字形并继续推进队列。

## 交互与导出

手机流程为姓名输入、实时校样、字体选择、确认落款。预览支持重写，同一份输入最多 12 个 Unicode 码点。手机横向滑动标本，桌面则采用网格。提交前按实际加载的字体测量字形，缺字显示补字提示；回执展示字体与落点坐标。

控制台沿用原有操作，包括开始、暂停、结束、重播、隐藏、恢复、删除、搜索和两种导出。4K PNG 将展签、计数、原位署名、生成艺术与二维码以 2 倍比例重新绘制。导出包含当时所有公开签到者的完整署名，包括队列中的公开记录。
